# Images

- `bg.jpg` — optional full-screen background photo. If present, it is used behind the dark gradient
  (see `#bg` in `assets/css/main.css`). Without it, the CSS gradient alone is the background.
- `logo.svg` — the hanxa wordmark (letters in the site font, geometric x mark). The header in `index.html` carries an inline copy using `currentColor`; regenerate both together if you change the mark.
- `favicon.svg` — the x mark alone on a dark tile.
